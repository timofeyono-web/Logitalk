
#  LogiTalk

LogiTalk is a lightweight and fast desktop chat application built in Python for real-time messaging.

##  Key Features

* **Multi-threaded Architecture:** Fast sending and receiving of messages in real time.
* **Modern Interface:** Sleek design powered by CustomTkinter with customizable UI elements.
* **Easy Connection:** Connect to a local or remote server using an IP address and port.

##  Tech Stack

* **Language:** Python 3.x
* **GUI:** `customtkinter`
* **Networking:** `socket`, `threading`
